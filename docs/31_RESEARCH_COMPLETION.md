# 历史升级工具说明

本文件名保留用于 `scripts/build_research_upgrade.py` 的打包引用。它不是当前部署验收结论，也不是首次安装入口。新使用者请从根目录 README 和[使用指南](USAGE.md)开始。

## 工具适用范围

`build_research_upgrade.py` 与 `build_observation_upgrade.py` 是针对已有安装和特定旧版本生成的增量升级工具。它们可能依赖本地旧部署包、修改前基线、冻结报告和验证记录；这些材料不随公开仓库分发。

对应 `apply_*.py` 工具会校验已有文件或接受的旧版本，并可能修改安装中的程序、配置及服务。实际目标通过 `--project` 或本地部署配置提供，不再内置某个环境的账号、目录或上传目标；它们仍是增量升级工具，不能当作通用安装程序直接执行。

构建工具读取 `.local/deployment.json` 或 `--deployment-config` 指定的文件，也接受显式的目标参数。参数说明见[本地部署参数](25_DEBIAN_DEPLOYMENT.md#本地部署参数)。生成的安装、上传说明会包含选定目标，部署包应保留在 Git 忽略的 `deploy/` 等本地目录，不作为公开发布附件。

独立升级包携带 `deployment_settings.py` 作为安装器的标准库辅助模块；私人 `.local/deployment.json` 不随包分发。升级构建器也会排除本次通过 `--deployment-config` 读取的配置文件；若它占用了必需升级文件的路径，会在创建输出前停止。生成的安装命令显式指定项目目标，目标服务器不需要依赖构建电脑的本地文件。

## 使用前需明确的输入

- 目标项目路径及当前安装版本。
- 原始版本保护材料和升级包校验结果。
- 研究数据、冻结报告、模型预算及尝试记录的完整备份。
- 实际服务入口、任务时间与失败回退方式。

缺少匹配的旧基线时应停止该增量升级流程，不通过跳过哈希校验或修改验收记录强行安装。普通源码安装和本地阅读不依赖这些历史材料。

本地运行、部署及备份入口见 `README.md`、`docs/USAGE.md` 和 `docs/25_DEBIAN_DEPLOYMENT.md`；旧环境的成功记录不能作为新环境已通过验证的证据。
