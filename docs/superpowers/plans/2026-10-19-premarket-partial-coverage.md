# 盘前局部覆盖实施计划

> 执行方式：按用户2026-10-19已确认的方案，使用 executing-plans 在当前会话实施；不提交、暂存或推送 Git。

**目标：** 名单少量缺失不阻断全部盘前研究，保留身份、来源、哈希、交易日期及风险校验，明确样本范围。

**设计依据：** 本会话用户已批准“已确认退出按生效日处理；未解释缺失隔离；已有可靠股票继续；全市场与样本统计分开；部署后补跑”。

**边界：** 原始名单快照及盘后严格规则不变。盘前显式启用局部覆盖，原有完整性标志不改成 true。只容许可枚举的历史成员缺失类阻断；源分页不全、身份冲突、权限和证据损坏继续拒绝该数据集。独立指数可继续。

**技术：** Python 3.12、既有来源和预算；不增加依赖或自动来源。

## 任务

- [x] 1. 新增纯函数名单覆盖评估，验证原快照、缺失标识与当前证券身份；通过显式参数接入名单读取和行业映射。局部模式不为未核验名单放宽停牌补充入口，无有效报价/停牌证据的证券保留为行情缺口。测试缺失两只可继续、默认严格模式拒绝、身份/日期/来源/哈希错误仍拒绝。
- [x] 2. 新盘前观察规则对有效报价样本计算相对强弱；缺失/无效报价不进入候选，样本与全市场口径独立，仍保留最多3方向/15深查/5观察。冻结并显示覆盖说明，新增报告版本，保持旧归档可读。
- [x] 3. 行情阶段保留独立指数降级；证券观察日与行情日范围分开。已核验的证券退出事件只影响生效日及之后的候选，不回写历史名单。测试真实边界与新旧报告。
- [x] 4. 相关回归、全量离线测试、独立代码审查。精确发布清单、现场只读复核、备份、服务器隔离测试、仅重启网页、核验归档和服务。
- [x] 5. 用户授权单次补跑：复用现有周五冻结行情，使用今天名单和实际资料截点；保留共享锁、额度、全部历史及原09:00报告。失败/不明不自动重试；验证最终归档及网页。

## 验收重点

1. 少量名单缺失可产生有据的方向/股票，不能由样本声称全市场广度完整。
2. 正确缺失列表不能掩盖错误证券身份、错日、来源不完整或自重算哈希后的证据冲突。
3. 行情缺失股票与已知ST/停牌/退市/不利风险不能进入观察名单。
4. 当名单整体拒绝时，独立且可靠的指数仍可支持有范围限制的市场倾向。
5. 补跑保留实际时间、原报告关联和次数，不重新采集已有完整市场证据，不回写历史。

## 恢复

发布前逐文件备份；应用回退恢复本轮源码，保留新版本报告、源快照、预算、首次观察与尝试记录。旧应用不保证显示新报告；不得改报告版本或回滚数据库冒充恢复。
