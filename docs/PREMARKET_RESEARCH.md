# 盘前研究与当前接入状态

核对日期：2026-10-14。目标是每天北京时间 09:00 阅读面向 3–10 个交易日波段的市场姿态、重点方向与关注股票。用户已确认先上线有限消息覆盖首版，并明确要求：资料不足也按已有有效证据分析，不能自动归为按兵不动。

2026-10-15授权调整：用户要求直接切换正式早报，并在下一天查看上线效果。允许先按现有有限覆盖启用，真实盘前日期和自然09:00运行保留为上线后验收项；下文“验收后切换”是原发布门槛，按本次授权调整执行。来源权限、实际日期、预算、失败和未知状态规则不变。源码分发模板仍默认关闭，只有明确部署配置启用。

## 代码路径

- `premarket/`：日期、市场广度与指数指标、姿态、技术优先级、事件校验、不可变报告和后续价格观察。
- `operations/premarket.py`：沿用全局日任务锁与历史尝试计数，管理阶段截止、降级、发布和复用。
- `viewer_premarket.py`：显示报告日、目标交易日、行情日期及实际发布时间，区别今日未生成与历史报告。
- `config/premarket_daily.json`：盘前候选配置。`config/sector_observation_daily.json` 仍为原正式配置。

只查看计划、不发起行情或模型调用：

```powershell
.\.venv\Scripts\python.exe -m ashare_daily run-daily --config config/premarket_daily.json --dry-run
```

`config/premarket_research.json` 的 `production_enabled` 默认是 `false`。不能仅修改开关就认为接入已通过验收。

## 判断与排序

市场姿态按已经核验的市场广度、指数趋势和成交活跃度分别判断，消息缺失不再自动否决已有量价结论。只有部分分量有效时给条件性倾向并注明依据范围；信号分歧或存在已知反面证据时说明具体原因；关键方向证据全部不可用时显示“暂无法判断”。完整度另行显示，不能把缺失写成零值或没有风险。技术分用于合格池内的优先级，按方向轮流选取，每方向最多两只，总数最多五只；旧相对强弱顺序作为对照保存。规则与版本兼容见[证据分量决策说明](PREMARKET_EVIDENCE_ADR.md)。

预选后完成公司资料核查，才可进入重点关注。缺失资料进入待核查，不自动解释为“无利空”。模型仅处理允许外发的文字，数字和决策在本地计算。规则是研究启发式，测试通过不代表验证了投资效果。

## 来源覆盖与运行验收

1. 首版按用户2026-10-14确认的有限范围接入财政部主站原创财政新闻、深交所本所要闻和巨潮候选公司公告。央行、国务院和证监会仍缺直接覆盖；这些缺口在每期覆盖记录中明确列出。财政部/深交所新来源已取得实际目录、正文及访问规则样本，但不能据此宣称覆盖全部宏观、货币政策或证券监管消息。
2. 巨潮公司公告已接入候选流程，并完成一个真实目录/PDF样本与离线回放；正式盘前环境、沪深候选的完整覆盖及自然任务仍待验收。目录截断、日期精度、正文失败和语义未核查均保留缺口。
3. 当前新来源正文只在本地处理，不上传第三方模型或在报告中全文转载。未核验的政策影响或公告语义不当成已知利好/利空；已有有效量价仍独立支持市场倾向，同时显示消息限制。个股公司资料与风险核查独立生效，未完成时进入待核查观察。
4. 还需在真实盘前时段验证源端报价日期，确认最近完整交易日的截面、当前证券名单和行业映射保持各自时间口径。

代码、部署和自然运行分别报告。实际发布按最新授权及私有运维入口切换现有单一定时器，保留预算与历史记录，不增加第二套早晚任务；尚未完成的真实日期与业务验收保持待验收状态。

## 本地来源接入

- `source_http.py` / `source_http_worker.py`：所有新来源和盘前旧资讯补充共享每轮 20 次 HTTP 上限，包含 robots 和失败请求；联网在可终止的子进程执行，消息截止覆盖整份响应读取。禁止自动跳转、自动重试及访问受限后的同源继续请求。
- `announcements.py`：按已经验证的证券代码与名称解析巨潮页面使用的公司标识，再查最多 5 只预选股的公告。每股只读 1 页、最多 30 条；总数或分页表明不完整时降级。身份映射不替代正式证券池。
- `pdf_text.py`：新增固定依赖 `pypdf==6.20.1`；其余依赖不升级。每份最多 5 MB、60 页，另有限制解压、文本长度和解析时间；扫描件、缺页文字、加密或验证页不能当成正文成功。
- `policy_sources.py`：央行可见目录日期、证监会目录与正文时间分别保留；网页生成时间、标题及征求意见稿均不等于正式生效事实。当前仅有保存样本的解析验证，访问受限来源保持禁用。
- `official_alternatives.py`：财政部主站目录只读取本主机且正文署名新闻办公室的原创文字，子站与转载内容不默认为已核查；深交所目录只提取已核对的固定字符串与可见日期，不执行脚本。深交所网页链接按声明指向首页，原始文章定位仍保存在证据记录。两项均每轮最多1页目录、2篇正文，共用原20次HTTP预算。
- `observations.py`：按来源、原始 URL 和内容版本持久保存首次观察；同一版本再次出现作为背景，不重复标成隔夜新增。

访问核对（2026-10-14）：财政部robots404，主站目录与原创正文200；深交所robots200空规则，目录、正文与法律声明200。央行原禁用规则不变；证监会robots302实际跳转到HTTP首页，未作为有效规则接受；发改委robots403，停止该源。缺失robots不是内容使用授权。真实样本结果、日期和哈希保存于私有验收记录。

公司核查的“clear”只表示完整查询的本期窗口未发现新公告，并不表示公司不存在历史风险。读到新公告后先进入语义待核查；风险关键词只给出定位类别，不自动断言利空、利好或用户卖出建议。财务资料核查仍独立生效。

来源声明与访问规则：[财政部](https://www.mof.gov.cn/)、[深交所法律声明](https://www.szse.cn/application/laws/)、[央行 robots](https://www.pbc.gov.cn/robots.txt)、[证监会法律声明](https://www.csrc.gov.cn/csrc/c100227/common_zcnr.shtml)、[巨潮资讯](https://www.cninfo.com.cn/)。当前许可判断仅限个人研究的有界本地读取，不适用于商业分发或模型全文外发。

## 真实盘前日期验收

`premarket/preflight.py` 提供独立验收入口，只允许真实北京时间08:30至08:50执行；不接受改日期伪装盘前。当天仅一次，独立目录保留尝试、原始名单、报价和结果；重复执行不能清空或重置尝试。当前证券名单在隔离数据库核验，四个板块各取一个已验证证券身份，只用一批报价核对上一完整交易日的源日期，模型调用为零。

2026-10-15 运行时限调整：`config/premarket_research.json` 的 `universe_max_seconds` 默认900秒（15分钟），用于盘前名单准备；行情阶段总上限仍为1200秒且不越过08:50。预检CLI支持 `--universe-max-seconds`（1–900），同样受实际剩余窗口限制，并预留20秒给报价与收尾。例：08:45开始时，名单有效预算最多280秒。这里只扩大运行时间，不扩大模型调用次数、新闻20次HTTP预算或自动重试次数。

名单准备仍包含完整证券池发现，因此增加时间可能使更多公开数据分页请求得以完成；900秒不是保证成功的时长，也不能把未读完名单当作完整。此前120秒运行的真实结果保留，不因配置变更回填成功状态。

样本通过只证明该次日期关系，不能代替全市场截面、指数、财务、消息、完整报告或第一次自然09:00任务验收。具体执行日程、部署状态与恢复入口以私有交接记录及实际定时器为准；不从本文推断已有自动验收安排，不新增第二套早晚日报。

## 新观察记录与恢复

新版本首次使用本地来源时，在 `data/operations/premarket_sources.sqlite3` 创建独立的 `source_observations` 表，以 `(source_id, original_url, content_hash)` 为主键，在事务中写入不可倒退的 `first_seen_at`。既有市场库和预算库不迁移、不回填历史首次观察时间；运行目录仍保存原始响应、哈希、时间和解析记录。

发布时先备份应用与配置，再安装锁定依赖，核对新数据库路径归属及写入权限；首次创建后可用 SQLite 完整性检查及重复版本查询验证主键和首次观察保留。失败即降级为来源不足，不丢弃原始记录。回退旧应用时保留该数据库与新报告，旧应用不读取它；再次升级时继续复用。不得为了回退应用而恢复旧预算、清空尝试记录或重置首次观察历史。
