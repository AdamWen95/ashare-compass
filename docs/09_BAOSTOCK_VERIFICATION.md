# BaoStock 接入说明

本路径保留给配置和诊断脚本中的来源引用。它说明当前仓库的实现约定，不是实时连通性报告；旧开发验收与请求元数据不随公开文档分发。

## 实现入口

项目锁定 `baostock==0.9.3`，适配代码位于 `src/ashare_daily/providers/baostock*.py`，字段质量检查位于 `src/ashare_daily/quality/baostock.py`。接口版本以项目 lock 文件与实际运行环境为准。

代码使用 `login/logout`、`query_trade_dates`、`query_stock_basic`、`query_history_k_data_plus` 等 SDK 能力。运行时校验错误码、返回字段、证券代码、目标日期和迭代完整性；不能仅以导入成功判断服务可用。

日线分别保存展示用原价与趋势计算用的复权版本，检查成交量、成交额、ST 和交易状态字段。供应商调整后的历史窗口不能与另一来源或旧调整版本随意拼接。

## 小样本身份和使用范围

基础资料中的“股票”类型本身不足以证明证券属于目标 A 股板块。全范围名单还需交易所、板块、证券类型及观察时间证据；小样本调用成功不能证明全市场覆盖。

先按已核对用途验证少量样本，再准备选定范围的历史及增量。请求失败、缺日、停牌和数据不足分别保留状态，不以模拟数据替代真实结果。
