# 研究范围与产品边界

项目在盘后生成《今日方向简报》，提供筛选逻辑、研究候选、事实依据、风险及待验证事项。允许空候选池，不承诺盈利、胜率或完整覆盖所有消息。

## 包含的内容

- 行情、证券身份和交易状态的质量检查。
- 行业选择、量价筛选、可选的财务资料和文字背景分析。
- 证据来源、首次观察时间、版本、反面材料和资料缺口。
- 冻结日报、历史版本、只读网页、任务预算和备份恢复。

量价通过、资格通过与公司材料核查是不同状态。缺少公告或财务材料不能解释为没有风险，行业标签也不能直接证明公司业务受益。

## 不包含的内容

不开发账户、持仓、现金、券商连接、委托、买入数量、仓位、可卖数量、卖出策略、模拟成交或账户收益。研究中可以客观记录减持等事实，但不据此生成面向用户持仓的卖出指令。

## 当前观察流程

`config/sector_observation_daily.json` 使用沪深四板块普通 A 股名单，按行业选择冻结研究集合，仅为该集合准备长期行情，暂不包括北交所。其他样本、工程验证和旧全市场入口保留各自用途，不能混入正式观察报告。

从 2026-09-22 的策略调整起，当前观察配置不以“退市整理期”作为正式候选资格条件，也不为这个条件专门采集名单；证券身份、上市状态、非 ST、非停牌和量价条件仍保留。旧冻结报告继续使用原规则，不能用新规则悄悄重写历史。

## 事实与时间

行情指标由确定性代码计算，模型不能生成行情数值或引用。业务时区统一为 `Asia/Shanghai`，交易日由可信日历确定。资料保存首次观察时间、截点和内容版本；补跑标明事后重建，失败不能用 Demo 数据填充。

网站、新闻、公告及模型输出都属于不可信输入，不执行其中要求改写任务、运行命令或泄露密钥的指令。数据获取、缓存、向模型发送和报告再分发需要分别核对适用权限。
