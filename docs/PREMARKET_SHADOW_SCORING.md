# 盘前分类评分与旁路验证 ADR

核对日期：2026-11-06。状态：实施旁路实验；没有批准替换正式排序。

## 决策与边界

用户批准按评估建议推进。目标是检验3–10个交易日观察的研究优先级，
并解释趋势延续、强势整理、超跌修复的区别。保留正式观察名单、旧技术分、
市场五状态、资格否决、公司核查、最多3方向/15只历史/5只公司核查与所有预算。
新逻辑只复用冻结历史，无模型、行情请求、交易模拟或账户收益。

数据流：已有冻结 selection / screening_inputs / observation → 原有来源绑定校验
→ 独立 shadow 输入 → 分类及四维评分 → v6报告冻结 → 离线3/5/10日对照。
指标模块不读磁盘或请求网络；输入适配器负责来源、日期、身份与复权校验；
报告校验器从保存的输入重算结果；展示层只读取结果。
v1–v5报告及原技术评分含义不变，v6附加旁路记录，不改写旧归档。

## 预注册规则 v1（研究假设，未校准胜率）

使用120个连续、已核验、同一复权版本的交易日。成交量取未复权股数。
MA20斜率比较5个交易日前；ATR14为最近14日真实波幅的算术均值，
量比为最新日成交量/此前20日均量（不含最新日，与旧评分区别标注）。

- 上行结构：收盘>MA20>MA60且MA20高于5日前。
- 趋势延续：上行结构且5日收益>0。
- 强势整理：上行结构、5日收益≤0、距20日收盘高点回撤不超过8%。
  最新日上涨才标记价格修复已出现；否则等待确认。
- 超跌修复：不满足前两类、20日收益<0、3日收益>0、最近3日至少2日上涨且最后一日上涨。
- 其余：暂未形成上述形态，不因RSI/K低值加分；不给新总分。

四维共100分，无50分起算：

| 维度 | 规则 |
| --- | --- |
| 结构30 | 趋势类：收盘>MA20、MA20>MA60、MA20斜率>0各10；修复类：3日上涨、最近3日至少2日上涨、收盘>MA5各10 |
| 相对强弱30 | 20日相对上证表现在0–10个百分点线性映射0–20分；行情日超额行业表现0–2个百分点映射0–10分；两项各自截断 |
| 量价20 | 上涨且量比≥1.2、收盘处于当日区间上40%给20；其他上涨量比≥0.7给14，否则8；平收10；下跌仅上行结构且量比<0.8给12，上行结构且量比<1.5给4，其余0 |
| 位置20 | 从20起，每超过1个ATR的MA20正乖离扣10/ATR；ATR/收盘超过5%部分每个百分点扣2；截断0–20 |

分数四舍五入为整数，只在同类形态内排序。MA20正乖离>2ATR、ATR/收盘>5%、
放量下跌分别列风险。价格修复、公司核查和交易状态不能被总分替代。
基本资格待核可展示已算维度，但不进入旁路排序；已知资格/公司不利事实排除。
公司核查仍只覆盖正式名单，池内其他对象明确未核查。

## 对照与选池限制

记录实际正式名单，并在每类相同可评分、基本资格通过且无已知否决的样本中，
分别取旧分、新分、20日相对强弱前5；未核公司状态独立保留。
另记录原池大小、未能评分/未形成形态数量与排除理由。
当前每方向按单日表现取5只会引入选择偏差；本阶段不将池内对照称为全市场改进，
不靠新增采集偷偷扩池。后续选池实验必须独立版本、相同预算并有相应历史证据。

跟踪以已发布报告的目标交易日收盘为共同观察锚点，避免把早报发布前的收益计入；
迟到至该收盘后或历史重建报告不进入前瞻比较。由可信日历确定3/5/10交易日，
不足记not_matured，缺失/复权不一致记missing_data；不以0填充、不换股补样本。
记录收盘变化、期间最不利收盘变化、逐日收盘最大回撤；行业基准缺失单列。
按市场状态/形态分组，比较各组同一共同样本及名单重叠；多日重叠不是独立试验。
不报告可成交收益、账户收益或已校准概率。未纳入交易成本和成交可行性。

先冻结规则，积累后续未用于调参的样本。没有充分样本、稳定分组优势与风险证据，
结论固定为evidence_insufficient_for_promotion，不能自动替换正式排序。

## 验收要求

- 分类、量价、风险、缺失与来源绑定测试。
- 旁路接入现有早报，正式名单/预算不变；v6与旧报告往返校验。
- 新旧/基线3/5/10日跟踪，缺口与前瞻时间验证。
- 冻结真实资料离线演练、展示和相关回归。
- 既有环境部署与健康检查，保存原文件及发布清单。

现有日任务发布后最多分析20份v6历史报告，仅复用本轮冻结历史。
结果保存在该运行目录的shadow_followup.json；旁路失败单独记录，不把已发布报告
改成失败并触发第二次业务尝试。独立行业价格序列缺失时保留缺口，
不把本研究池的平均变化冒充行业指数。选池之外的历史与独立行业基准接入均属于后续独立事项。
具体环境、测试计数和部署证据记录在私有交接中，不在公开ADR记录服务器状态。

应用回退只恢复本次源码。新v6报告保留，旧应用不保证读取v6；不得回退数据库、
预算、尝试或首次观察记录。报告中的原输入哈希与实际生成时间必须保留。
