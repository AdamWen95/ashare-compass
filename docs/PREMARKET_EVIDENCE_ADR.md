# 盘前判断按有效证据分量计算

日期：2026-10-14。状态：按用户当日明确修正实施。

用户要求：资料不足时也按照当前资料分析，不能自动归为“按兵不动”。该要求替代早期首版中的缺消息或任一资料缺失即停止判断规则。

## 决策

市场倾向和资料完整度分别保存。新规则为 `premarket-stance-v2`，指数趋势、全市场上涨广度、指数成交活跃度分别验证、计算和展示；缺失项不补值，也不连带删除其他已核验信息。

| 可用证据 | 输出方式 |
| --- | --- |
| 完整有效量价偏强、已有合格方向，但消息未齐 | 保留进攻倾向，明确消息缺口和结论条件 |
| 已核验广度明显偏弱，或指数与广度共同偏弱 | 保留防守倾向，消息缺口不会遮蔽已有弱势 |
| 只有指数趋势、或只有完整全市场广度有效 | 用该分量给条件性倾向，注明仅指数或仅广度的依据范围 |
| 已有有效信号分歧、成交偏弱或无合格方向 | 按兵不动并说明具体信号原因；不把缺资料当唯一原因 |
| 指数趋势和全市场广度均不可用 | “暂无法判断”，仍保留已有事实；不伪装成中性或按兵不动结论 |

完整输入时保留既有阈值：上涨广度60%、指数MA20及其方向、五日动量和成交额均值支持进攻；上涨广度不高于30%且中位数为负，或指数低于MA20且上涨广度不高于40%，支持防守。部分输入时只采用有效分量，已知不利量能不能被遗漏。指数单独走弱须同时低于MA20、MA20下行且五日动量为负。

已核验且尚未解决的市场反面证据仍可取消进攻；“没有采到消息”不等于已存在反面事件，也不等于没有风险。个股的证券资格、量价条件、公司资料与反面证据继续独立核查，未完成时保留技术评分和观察理由，不伪装成已充分核查的重点推荐。

全市场广度必须有完整且身份正确、同日同口径的分母；局部候选股票的样本广度不能升级为全市场结论。指数只允许完整价格及日期身份核验后的趋势，成交额缺失只使成交活跃度不可用，价格、日期、身份等错误仍拒绝。

## 数据流及边界

`market.py` 输出独立分量状态与有效数值；`decisions.py` 只使用已验证分量，输出倾向、依据范围、已有证据和限制；报告、网页和导出使用同一结果。资料覆盖与成功采集水位继续独立记录，不能因为给出了判断就声称采集完整。

个股筛选或历史准备失败时，适配层保留已经验证的市场事实。失败阶段可能已经发出请求时，只回读经过验证的缓存，不另发同一请求。指数成交额缺失产生的价格投影另存 `benchmark/market_price_snapshot.json`，不覆盖旧 `benchmark_snapshot.json`，不放宽旧个股相对强弱/评分路径的完整性要求。

## 持久化与回退

新报告写 `premarket-brief-v2`，读取器同时支持旧v1及其原 `premarket-stance-v1` 规则。旧报告不回填、不重算、不改哈希。v2归档校验会依据报告中的市场、方向和已核验事件重新计算完整姿态字段，防止文字结论与事实不一致。

无需迁移历史业务表或报告。发布先更新兼容v1/v2的读取器及决策模块，再允许生成v2。回退旧应用时保留v2文件和独立指数价格投影；旧应用不保证能读v2，不能把报告版本改回v1来绕过校验。预算、尝试、首次观察及旧冻结数据均不回退或清理。

## 验证

回归覆盖消息缺失下的强弱判断、分量独立性、不能把样本当全市场、真实 `missing_amount_cny` 质量标记、已知风险/弱量能、没有有效方向证据、v1冻结报告兼容、v2结论绑定、个股准备失败保留市场事实以及缓存恢复不重试。测试通过只证明实现符合规则，不证明投资效果。
