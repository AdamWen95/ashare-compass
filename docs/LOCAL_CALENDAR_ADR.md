# ADR：独立的本地交易所日历

状态：采用。决策与来源核对日期：2026-10-09。

## 问题与决定

每个新日期都等待行情服务登录才能取得交易日历，会把行情源暂时不可用扩展为整轮研究任务的入口阻断。日历是交易所发布的交易安排，应独立于当晚行情服务连接。

参考 [Intelligent-stock-selector 的 quality.py](https://github.com/ktoking/Intelligent-stock-selector/blob/b0f258521cac896a63d32be758c07405cc89423e/daily_direction/quality.py)，该项目按市场选择 `exchange_calendars` 的 XSHG、XNYS、XHKG，并另行验证行情是否属于预期交易日。本项目采用本地日历与行情分离的做法，独立实现来源校验；不复制最近交易日替换、80%覆盖门槛或静态候选池降级。

采用固定 `exchange-calendars==4.13.2`，许可证 Apache-2.0。其 XSHG 实现使用预先列出的休市日，源码声明覆盖至2026年。依赖及必要传递依赖由两平台锁文件固定版本和wheel哈希，既有依赖不升级。本项目日历模块另外固定XSHG源码哈希，并将2024—2026年完整日状态与官方公告逐日比对。实际日期由库提供，比对不通过时失败，不根据星期生成替代日历。

官方年度依据：

- 上交所：[2024](https://www.sse.com.cn/disclosure/dealinstruc/closed/c/c_20231226_5733941.shtml)、[2025](https://www.sse.com.cn/disclosure/dealinstruc/closed/c/c_20241223_10767110.shtml)、[2026](https://www.sse.com.cn/disclosure/dealinstruc/closed/c/c_20251222_10802510.shtml)。
- 深交所交叉核对：[2024](https://www.szse.cn/disclosure/notice/t20231226_605108.html)、[2025](https://www.szse.cn/disclosure/notice/t20241223_611283.html)、[2026](https://www.szse.cn/disclosure/notice/general/t20251222_618087.html)。
- 当前节后日期核对：[2026年中秋节、国庆节安排](https://www.sse.com.cn/disclosure/announcement/general/c/c_20260915_10832273.shtml)。10月8日恢复开市，10月10日为周末休市；不能将工作日调休表当作证券交易日历。

## 契约、数据流与边界

名单配置 `calendar_provider` 支持 `baostock`、`exchange_calendars`，缺省仍为前者，当前沪深配置显式选择后者。本地源只确认指定日期，不挪到最近开市日，不隐式切换在线供应商。

新增 `exchange-calendar-cache-v1` 包，独立标记 provider、source_kind、库版本、日历源码哈希、核对日期和公告链接，记录明确的2024-01-01—2026-12-31覆盖区间、完整自然日布尔状态、首次观察时间、内容哈希和包哈希。模式严格区分 research/offline_test。本地证据不标记为实时网络成功，也不制造 BaoStock SDK 响应。

`calendar.verify_calendar_packet` 分别验证两个来源格式。F1写入同一配置缓存根后，历史准备通过既有缓存根复用；320日窗口、21日基准和停牌补证都读取这份证据。同源保留来源时间版本规则，不同来源同日有矛盾则阻断。日期来源改变不改变行情数值、证券资格或正式候选条件。

这是有限覆盖的本地规则版本：2027年、未核验范围、缺包/版本不一致、哈希或模式错误均不能当作开市证明。维护者应在交易所发布临时休市或新年度安排时复核、测试并升级受审版本及覆盖区间；当前版本没有自动订阅或发现临时公告的能力。扩展覆盖必须有明确公告依据，不能只修改结束日期。

## 迁移与恢复

无数据库结构变更，无旧数据回填。先安装新增锁定依赖，再部署来源适配、统一验证、消费者和配置；用旧缓存加新临时验证包验证窗口与冲突后再启用。既有 `f1-calendar-cache-v1` 属于持久化契约，继续严格读取，不改原字节或时间；新包首次使用时新增，重复读取保留首次观察时间。

应用回退应同时恢复配置与相应源码。新包保留为独立证据，旧版本会因格式不符而拒绝它，不会把它作为BaoStock缓存；原有BaoStock包和业务数据库无需恢复。新增依赖可保留，或仅移除本次新增包，不能借回退升级、卸载其他依赖。备份与实际发布证据保存在使用者私有运维目录。

## 验收

离线验证交易日、休市日及周末调休，固定源版本、范围、首次观察时间、完整性和哈希；验证可信本地包使F1和历史窗口零日历网络请求，并覆盖混合旧缓存、跨源冲突、停牌证据引用与旧报告读取。真实名单、行情、模型和报告发布仍分别验收；本地日历测试通过不等于供应商恢复或自然简报已生成。
